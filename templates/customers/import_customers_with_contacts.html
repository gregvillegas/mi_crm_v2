Import Customers With Multiple Contacts

Legacy Customer Import
Safest single-file option: This importer keeps the existing primary contact on the `Customer` record and stores extra contacts as related `CustomerContact` rows. That avoids changing customer IDs or breaking proposal, activity, mailing, ticket, and reporting links.
CSV Format Instructions:
  • Required base columns: `company_name`, `contact_person_name`, `email`
  • Optional base columns: `contact_person_position`, `phone_number`, `address`, `industry`, `territory`, `active_status`, `salesperson_initials`
  • Additional contacts: use `contact_2_*` through `contact_5_*` columns for up to 4 extra contacts
  • Per-contact fields: `contact_N_name`, `contact_N_position`, `contact_N_email`, `contact_N_phone`, `contact_N_is_primary`
  • Primary contact safety: the main contact always remains on the `Customer` row for compatibility with other apps
  • Salesperson match: `salesperson_initials` must match an active salesperson initials value
  • Download customer + contacts sample CSV
Need the old format? Use the legacy customer import for one primary contact only, or the contacts-only import to add related contacts to existing customers.
